# Simple Quiz App

A simple command-line quiz application built with Python. This project asks multiple-choice questions, checks the user's answers, and displays the final score.

## Features

- Multiple-choice questions
- Instant feedback for each answer
- Final score display
- Easy to add or edit questions
- Beginner-friendly Python project

## Technologies Used

- Python 3

## Project Structure

```
Simple-Quiz-App/
│
├── quiz.py
└── README.md
```

## How to Run

1. Make sure Python 3 is installed.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the following command:

```bash
python quiz.py
```

or

```bash
python3 quiz.py
```
